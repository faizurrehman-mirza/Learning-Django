# 📘 Day 1 — Getting Started with Django

## What this chapter covers
Setup — no project code yet, just getting the environment ready before touching Django.

## 🧠 Explanation
Django is a Python web framework that handles a lot of the repetitive backend work — routing URLs to code, talking to a database, rendering pages — so you're not rebuilding that plumbing for every project.

Day 1 covered:
- Confirming Python is installed and working.
- Installing Django with `pip install django`.
- Understanding why each project gets its own virtual environment instead of a global install — different projects can need different Django versions, and a global install gets messy fast.
